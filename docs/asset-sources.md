# Asset and data sources

## Contribution data
- Source: https://github.com/users/Jainabhi90/contributions (public, no auth).
- Contains exactly what the public profile shows, including the anonymized
  private-contribution counts the user already publishes (Settings > Public
  profile > "Include private contributions on my profile").
- Never enrich these assets with private repo names, per-repo private stats,
  or data pulled via the user's authenticated integrations.
- Cached snapshot: data/contributions.json (regenerated by the workflow).

## Track scale
- Grid cells: raw daily counts mapped to GitHub's own level 0-4.
- Track elevation: centered 3-week moving average of weekly totals, linear
  scale from 0 to the max smoothed weekly total. Smoothing is a visual
  choice; the underlying daily data is unchanged in the cells and tooltips.
- Stats strip numbers come straight from the same dataset.

## Character artwork
- User asked for the exact Kick Buttowski character (Disney IP). Candidate
  images came from Pinterest pins; no source grants redistribution rights.
  Licensing is NOT cleared. Documented here so the status is never
  misrepresented: these are user-chosen references, not licensed assets.

## Generator
- scripts/generate_stunt_track.py: original work for this profile, stdlib
  Python only, no third-party code copied. snk (Platane/snk) was used as a
  data-path reference only (its repo carries no LICENSE file, so no code
  was taken from it).

## Telemetry data
- Contribution velocity: same public contributions endpoint.
- Repo activity and languages: unauthenticated api.github.com endpoints
  (/users/<user>/repos?type=owner and /repos/<owner>/<repo>/languages),
  public non-fork repos only (14 at generation time). Private repos are
  never queried or named. Language bars are byte shares, labeled as such,
  never skill percentages.
- Build status (brief section 10D) is intentionally NOT generated: NioLearn
  and EduOS are private. That panel belongs to hand-written, user-approved
  copy, not automation.
